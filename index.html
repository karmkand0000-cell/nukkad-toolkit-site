Nukkad Toolkit

Nukkad Toolkit is a private desktop tool used only by the team of the YouTube channel Nukkad Live Adda. It runs on the channel owner's own laptop.

It uses the YouTube Data API and YouTube Analytics API to:

  • upload the channel's own videos, set thumbnails, playlists and schedule them (private by default),
  • list comments on the channel's own videos, hold abusive comments for review and post replies,
  • build a weekly performance report of the channel.

It is not offered to the public and does not access any other channel.
