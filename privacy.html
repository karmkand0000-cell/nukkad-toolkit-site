Privacy Policy

App: Nukkad Toolkit · Last updated: 2 November 2026

Who uses it

Nukkad Toolkit is a private desktop tool used only by the owner of the YouTube channel Nukkad Live Adda to manage that channel. It is not offered to the public.

What data it accesses

With the channel owner's permission (Google OAuth), the tool uses the YouTube Data API and YouTube Analytics API to upload the channel's own videos and thumbnails, manage its playlists, read and moderate comments on its videos, post replies, and read the channel's analytics.

Where data is stored

All data stays on the channel owner's own computer: the OAuth token, generated reports, comment lists and upload logs. Nothing is sent to any server run by us, and no data is sold, shared or used for advertising. Data goes only to Google's own APIs, to carry out the actions listed above.

Google API Services

Nukkad Toolkit's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube data is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local token file on the computer also removes the tool's access.
